Welcome to my academic homepage!

I am Junhao Chen, a master's student majoring in Software Engineering at Nanjing University of Aeronautics and Astronautics. My research focuses on Intelligent Software Engineering, with particular interests in the integration of artificial intelligence techniques and software engineering practices.

Research Interests
======

My research interests include:

- Intelligent Software Engineering
- Large Language Models for Software Engineering
- Software Defect Detection and Localization
- Program Analysis and Code Understanding
- Automated Software Testing
- Intelligent Agents for Software Engineering

I am interested in exploring how artificial intelligence, machine learning, and large language models can improve the efficiency, reliability, and automation of software development, testing, maintenance, and evolution.

Research Direction
======

My current research direction is Intelligent Software Engineering. This field aims to apply artificial intelligence techniques to key software engineering tasks, including code generation, code understanding, defect detection, test generation, program repair, and software maintenance.

In my research, I focus on bridging advanced AI-based methods with practical software engineering scenarios. I am particularly interested in developing approaches that are not only effective in experimental settings but also interpretable, reproducible, and applicable to real-world software development workflows.

I will continue to update this website with my latest research progress and academic work. I welcome communication and collaboration with researchers and students interested in intelligent software engineering, software testing, program analysis, and large language models for software engineering.
